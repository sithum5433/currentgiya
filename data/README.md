The local `sri-lanka-districts.geojson` contains the 25 Sri Lankan ADM2 district boundaries published by [geoBoundaries](https://www.geoboundaries.org/). The server uses these polygons to derive district leaderboard names from report coordinates. The file stays on the server; it adds no download to the normal page or the lite page.

Source metadata: [geoBoundaries LKA ADM2 API](https://www.geoboundaries.org/api/current/gbOpen/LKA/ADM2/). Boundary ID: `LKA-ADM2-46371173`; represented year: **2017**; source update: **19 January 2023**; build: **12 December 2023**. Retrieved **19 October 2026**. The API reports **25** administrative units.

The downloaded file is the [pinned geoBoundaries simplified GeoJSON at commit `9469f09`](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/LKA/ADM2/geoBoundaries-LKA-ADM2_simplified.geojson). Its original SHA-256 is `90c7e2940f78f85d9810a1f0915627b660a2b6efe381c2becf245b4cbaa8286c`. For this repository, JSON was minified, unused metadata was removed, and the source `shapeName` and `shapeISO` fields became `name` and `iso`; the English ` District` suffix was removed from names. **Coordinates, polygons, island components and holes are unchanged from that upstream simplified file.**

The 25 names are Ampara, Anuradhapura, Badulla, Batticaloa, Colombo, Galle, Gampaha, Hambantota, Jaffna, Kalutara, Kandy, Kegalle, Kilinochchi, Kurunegala, Mannar, Matale, Matara, Monaragala, Mullaitivu, Nuwara Eliya, Polonnaruwa, Puttalam, Ratnapura, Trincomalee, and Vavuniya.

These are simplified, dated map boundaries, so results close to a district boundary or coastline can be uncertain. `districtFor(lat, lng)` performs point-in-polygon containment, supports `MultiPolygon` islands and holes, and returns `null` for uncovered points or ambiguous shared borders. It never substitutes the nearest district. This dataset does not establish a transformer, phase, street-level service boundary, or official outage status.
